## בקצרה

- **הצורך:** היום כל שאלה שלה עוברת דרך מבוגר: לוח מילים קבוע וסייעת שמנחשת. זה איטי, מתיש, ולא לבד.
- **הפתרון:** שיעורים בקטעים של דקה, לוח תקשורת שמשתנה אחרי כל קטע, זיהוי עייפות, והבחנה בין ניחוש לידיעה.
- **עלות:** כ-29 ש"ח לחודש לכל ילדה, על המחשב הקיים בבית.
- **השפעה:** יעד של 70% מהקטעים בלי עזרה, ו-80% התאמה להערכת המורה והקלינאית. פיילוט של 5 משפחות ל-8 שבועות.
- **קהל יעד ראשון:** כיתות א׳-ג׳, קריאה וחשבון. החזון: א׳-י״ב.
